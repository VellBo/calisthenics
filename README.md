# Калистеника — личное PWA

Программы с собственным весом, лестницы навыков, плеер тренировки с таймером и блок для спины при гиперлордозе.
Без сборки и зависимостей: чистый HTML/CSS/JS. Данные хранятся в браузере (localStorage), резервная копия — в «Настройках».

## Запуск на компьютере

```bash
node server.js
```

Открыть http://localhost:5173

## Что внутри

- `js/data.js` — упражнения, программы, лестницы навыков, треки для спины. Новые программы и упражнения добавляются здесь.
- `js/app.js` — экраны, плеер тренировки, прогресс, хранение.
- `css/styles.css` — оформление.
- `sw.js` — офлайн-кэш. После изменений в файлах увеличь `CACHE` (`calisthenics-v2` и т.д.), чтобы телефон подтянул обновление.

## Как работает прогрессия

Если в тренировке выполнены все подходы упражнения на цель — в следующий раз цель вырастет на 1 повтор (или на 5 секунд для статики).

## На телефон

Для установки как приложение (офлайн, иконка на главном экране) нужен HTTPS-хостинг, например GitHub Pages или Netlify.
После публикации: Android/Chrome — меню → «Установить приложение»; iPhone/Safari — «Поделиться» → «На экран „Домой“».
